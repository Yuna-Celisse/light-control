# PCB 布局与布线复核记录

2026-11-10，目标为工作区 light-control.kicad_pcb，裸芯片 ESP32-S3FN8 四层板。全部源设计变更经 Konnect MCP 实时 IPC 完成。本记录描述已保存源文件。

## 已完成修复

1. 晶振 Y1 下方的 In2.Cu VBUS_DET 原斜线穿过晶振投影，已改为沿晶振上方与左侧绕行。时钟输入输出保持顶层，无新增时钟过孔。首次候选产生的铜冲突已在后续迭代消除。EN_760、EN_850 精确线段几何复核后未穿过晶振本体，恢复原路径。
2. U2 降压电源 C6 100nF 的 VIN 支路由经 C5 焊盘绕行改为直接到 U2 VIN。新支路使用 0.3mm 线宽。电容位置保持原坐标。
3. U101短距TIA输出反馈支路已缩短，增加两颗过孔，负输入节点保持原状。
4. 经 IPC 重填全部铺铜，再保存。随后以保存文件运行完整 KiCad DRC。

## 验证结果

- 实时IPC板信息确认4层、115网络、166器件。查询并保存最终走线证据 本次 IPC 回读记录（本地）。
- checks/drc.json 为铺铜实时重填并保存后的KiCad检查，0 errors、0 warnings、0 unconnected、0 schematic parity。
- checks/erc.json，KiCad 10.0.7，0 errors、0 warnings。
- 本地聚合复核报告覆盖11个原理图文件、11个sheet实例。聚合报告的电源告警含跨页遗漏与将VBUS_DET检测信号当电源的启发式项，未盲目增加器件。
- 自动检查与当前几何证据不足以证明噪声、晶振起振裕量、USB阻抗及实板性能满足指标。整体电气设计审查仍有待完成项。
