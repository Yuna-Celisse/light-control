# light-control BOM 导出说明

导出日期：2026-10-29。来源为当前已保存的根原理图及其 10 个子页，使用 KiCad 10 官方 CLI 导出。

- `light-control-BOM.csv`：按参数、封装、厂家、MPN、容差、介质、采购状态等完整字段分组的 BOM。
- `light-control-BOM-detail.csv`：逐位号明细。
- 数量：166 个位号，80 个分组，总数量 166。
- 当前 DNP 和排除 BOM 数量均为 0；分组导出启用了排除 DNP。
- H1–H4 是板上安装孔，TP1–TP3 是板上测试焊盘，共 7 项，保留用于设计核对，不作为独立采购元件。
- 其余 159 个元件中，有 89 个尚未填写 MPN，导出保持为空，不猜测采购型号。
- U3、U6 保留原有 ProcurementStatus 提示，包装后缀及认可供应商待确认。

校验：明细、分组与新导出网表位号覆盖一致；数量一致；参数、封装、厂家及 MPN 等字段与网表一致；PCB 的 166 个封装位号与原理图一致。源文件 SHA256 记录于 verification.json。

CSV 为 UTF-8（带 BOM），可用 Excel 打开。空白表示原理图未提供该字段。未补充价格、库存、供应商料号或未验证的器件替代。本次没有修改电路或重新执行 DRC/ERC。
